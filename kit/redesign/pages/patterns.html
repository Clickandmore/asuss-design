أنواع الشاشات الأربعة

قبل تصميم أي شاشة: حدّد نوعها، ثم اتبع ترتيبه كما هو.

جدول (قائمة) أي قائمة سجلات. لا تُبنى صفحة جديدة: يُضاف قسم في «السجلات».
  1. عنوان + سطر وصف + «جديد»
  2. تبويبات الإدارة
  3. شرائح الحالة بأعدادها
  4. بحث + فلاتر
  5. الجدول ← لوحة التفاصيل
مثال: عقود الاستقدام ← عرض سجل لوحة جانبية تفتح من الصف. الأهم أولًا، والإجراء التالي في الأسفل.
  1. النوع + الرقم + الحالة
  2. تنبيه إن وُجد
  3. المراحل
  4. الأطراف
  5. البيانات ← المالية
  6. الإجراءات
افتح أي عقد ← إضافة وتعديل أقسام مرقّمة في عمود، وفهرس جانبي، وشريط حفظ ثابت.
  1. رجوع + عنوان + سطر
  2. قرار يغيّر النموذج أولًا
  3. أقسام بعمودين
  4. فهرس + ملخص حي
  5. شريط الحفظ
مثال: سيرة ذاتية جديدة ← لوحة وتقرير أرقام ثم ما يحتاج إجراء ثم التفاصيل. كل رسم له عرض جدول.
  1. 4 أرقام رئيسية
  2. يحتاج إجراء اليوم
  3. توزيع ومراحل
  4. آخر السجلات
مثال: لوحة المعلومات ←
